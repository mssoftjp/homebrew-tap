# Maintaining this tap

Each cask belongs to one app. The app's own repository generates the cask from its
notarized release; this repository only publishes it.

| Cask | Generated by | Release steps |
|---|---|---|
| `Casks/lazyspace.rb` | `script/prepare-release.py` in [LazySpace](https://github.com/mssoftjp/LazySpace) | [RELEASING.md](https://github.com/mssoftjp/LazySpace/blob/main/packaging/RELEASING.md) |

- A release replaces only its own cask, after the matching GitHub release is published.
  Do not edit a generated cask by hand; fix the app's template and generate it again.
- A new app adds `Casks/<token>.rb` (the token is the app name in lowercase, with hyphens
  between words), a row in this table, and a row in the README.
- Before pushing, run `brew style Casks/<token>.rb`.
